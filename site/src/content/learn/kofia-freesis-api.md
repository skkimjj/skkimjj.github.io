[과거 주가 데이터 받는 법](/learn/krx-historical-price-data/) 편에서 한국거래소 시세를 엑셀과 Open API로 받는 방법을 정리했습니다. **API**(Application Programming Interface)는 프로그램끼리 데이터를 주고받는 규격입니다. 이번 편에서는 **금융투자협회** 데이터를 같은 방식으로 받는 방법을 다룹니다. 투자자예탁금·신용융자 잔고·반대매매 금액처럼 시장의 자금 흐름을 보여 주는 숫자는 거래소가 아니라 금융투자협회가 집계하기 때문입니다.

"금투협 API"를 찾을 때 먼저 알아 둘 사실은 세 가지입니다.

- <mark>협회 통계 포털인 **FreeSIS에는 자체 Open API 메뉴가 없습니다.**</mark>
- 프로그램으로 받는 공식 경로는 **공공데이터포털**(data.go.kr)이고, 제공기관 이름도 금융투자협회가 아니라 **금융위원회**로 적혀 있습니다.
- 그 API가 제공하는 통계는 **8가지**입니다. FreeSIS 화면에 있는 통계 전체가 API로 나오지는 않습니다.

아래에서는 FreeSIS 화면에서 내려받는 방법, 공공데이터포털 API의 신청 절차와 호출 예시, 그리고 같은 날짜의 숫자를 두 경로에서 대조했을 때 드러난 차이를 차례로 정리합니다.

## FreeSIS 화면에서 내려받기

**FreeSIS**(금융투자협회 종합통계 포털, [freesis.kofia.or.kr](https://freesis.kofia.or.kr/))는 **KOFIA**(Korea Financial Investment Association, 금융투자협회)가 자본시장 통계를 한곳에 모아 둔 사이트입니다. 협회의 다른 사이트(전자공시서비스·채권정보센터)와 어떻게 다른지는 [주식 데이터 무료로 보는 곳](/learn/where-to-find-market-data/) 편에 정리했습니다.

첫 화면 상단 메뉴는 주식·채권·파생상품·자산관리·펀드·자문일임·신탁·단기자금·금융투자업자의 9개 분류입니다(2026년 11월 21일 기준). 자주 찾는 두 화면의 경로는 다음과 같습니다.

| 화면 | 경로 | 제공 항목 |
| :-- | :-- | :-- |
| **증시자금추이** | 주식 > 증시자금 > 증시자금추이 | 투자자예탁금, 장내파생상품 거래예수금, 대고객 RP 매도잔고, 위탁매매 미수금, 실제 반대매매금액, 미수금 대비 반대매매 비중(%) |
| **신용공여 잔고 추이** | 주식 > 신용공여현황 > 신용공여 잔고 추이 | 신용거래융자·신용거래대주(전체·유가증권·코스닥), 청약자금 대출, 예탁증권 담보융자 |

**투자자예탁금**은 투자자가 주식을 사려고 증권사 계좌에 넣어 둔 돈으로, 이 화면에서는 장내파생상품 거래예수금을 뺀 값입니다. **RP**(Repurchase Agreement, 환매조건부채권)는 증권사가 일정 기간 뒤 되사는 조건으로 고객에게 파는 채권입니다. 신용거래융자와 반대매매의 뜻은 [반대매매란](/learn/margin-and-forced-liquidation/) 편에서 다뤘습니다.

화면을 열면 **자료주기는 「일간」, 조회기간은 「3개월」이 기본값**으로 설정돼 있습니다. 기간을 바꾸고 `조회`를 누르면 표와 차트가 함께 나오고, `EXCEL저장`·`XLS저장`·`PDF저장` 버튼으로 파일을 내려받을 수 있습니다. 차트는 `차트저장` 버튼을 누르면 이미지로 따로 저장됩니다.

<mark>화면의 금액 단위는 **백만원**입니다.</mark> 예를 들어 2026년 11월 19일 신용거래융자 전체는 화면에 `26,083,277`로 표시되며, 이는 26조 833억원입니다. 뒤에서 볼 API는 같은 값을 **원 단위**로 주므로, 두 경로의 숫자를 섞어 쓸 때 가장 먼저 맞춰야 할 것이 단위입니다.

공개 시점도 확인해 둘 필요가 있습니다. 11월 21일(토)에 확인한 FreeSIS 첫 화면에서 코스피 지수와 국고채 금리의 최신 값은 11월 20일이었지만, **투자자예탁금·신용융자 잔고·CMA 잔고는 11월 19일**이 가장 최근이었습니다. 증권사에서 자료를 모아 집계하는 통계는 시장 지표보다 늦게 공개됩니다. **CMA**(Cash Management Account, 종합자산관리계좌)는 증권사가 운용하는 수시입출금식 계좌입니다.

## FreeSIS에는 자체 Open API가 없다

2026년 11월 21일 FreeSIS의 전체 메뉴와 첫 화면을 확인한 결과 **Open API 신청 메뉴는 없었습니다.** 금융투자협회 고객센터 게시판에는 2020년 3월에 FreeSIS 통계를 API로 받을 수 있는지 묻는 글이 올라오기도 했습니다.

<mark>공식 API는 **공공데이터포털**에 있습니다.</mark> 금융위원회가 2021년 11월 16일부터 금융투자협회 데이터를 연계받아 공공데이터포털로 개방하고 있고, 그래서 제공기관이 금융위원회(금융공공데이터팀)로 표시됩니다. 포털에서 「금융투자협회」로 검색하면 나오는 API 가운데 협회 데이터를 제공하는 것은 다음 5종입니다.

| API 이름 | 기능 수 | 제공 내용 |
| :-- | :-- | :-- |
| **금융위원회_금융투자협회종합통계정보** | 8 | 신용공여 잔고, 증시자금, 펀드 순자산, CMA 등 (아래에서 자세히 설명) |
| 금융위원회_펀드상품기본정보 | 1 | 펀드표준코드, 펀드 명칭 등 기본정보 |
| 금융위원회_금융투자회사공시정보 | 2 | 증권사 퇴직연금 수익률, 금융투자회사별 주식거래 수수료 |
| 금융위원회_금융투자협회기타공시정보 | 2 | 외국투자증권 회사별 현황, 파생결합증권 중도상환가격비율 |
| 금융위원회_소매채권수익률정보 | 1 | **서비스 폐지** — 2022년 3월 25일까지의 과거 데이터만 제공 |

시장 자금 흐름을 보려는 사람에게 필요한 것은 첫 번째 「금융투자협회종합통계정보」입니다.

## 종합통계정보 API의 8가지 기능

| 기능(주소에 넣는 이름) | 제공 내용 | 갱신 |
| :-- | :-- | :-- |
| 업권별신탁규모 (`getTrustScaleInfo`) | 업권별 신탁 고객수·계약수·수탁총액 | 월 1회 |
| 펀드순자산총액 (`getFundTotalNetEssetInfo`) | 펀드 유형별 순자산 총액 | 일 1회 |
| 일자별CMA현황 (`getCMAStatus`) | CMA 일자별 잔고 | 일 1회 |
| **신용공여잔고추이** (`getGrantingOfCreditBalanceInfo`) | 신용거래융자·대주, 청약자금 대출, 예탁증권 담보융자 | 일 1회 |
| **증시자금추이** (`getSecuritiesMarketTotalCapitalInfo`) | 투자자예탁금, 위탁매매 미수금, 반대매매금액과 비중 등 | 일 1회 |
| DLS/DLB발행동향 (`getDLSAndDLBInfo`) | 파생결합증권 발행 건수·금액 | 월 1회 |
| ELS/ELB발행동향 (`getELSAndELBInfo`) | 주가연계증권 발행 현황 | 월 1회 |
| 국내투자자의 해외파생상품거래동향 (`getDerivationProductTradingInfo`) | 국내 투자자의 해외 파생상품 거래 실적 | 월 1회 |

**ELS**(Equity Linked Securities, 주가연계증권)와 **DLS**(Derivatives Linked Securities, 파생결합증권)는 주가지수나 금리·원자재 가격에 따라 수익이 정해지는 상품이고, ELB(Equity Linked Bond)·DLB(Derivatives Linked Bond)는 비슷한 구조에 원금 지급을 약속한 파생결합사채입니다.

펀드순자산총액의 기능 이름에 있는 `Esset`은 오타처럼 보이지만 실제 이름이므로 그대로 써야 합니다. `Asset`으로 고쳐 호출하면 오류가 납니다.

<mark>FreeSIS 화면에 있는 **대차거래 추이, 채권 최종호가수익률, 신용거래 체결주수 추이는 이 API에 없습니다.**</mark> 원하는 통계가 목록에 없다면 신청을 잘못한 것이 아니라 **API가 제공하는 범위 자체가 좁기** 때문입니다. 이 통계들은 FreeSIS 화면에서 파일로 내려받을 수 있습니다. 대차거래는 같은 포털에 「금융위원회_주식대차정보」·「금융위원회_주식 대차 거래 정보」 API가 따로 있습니다. 다만 두 API는 **상업적 이용이 금지**돼 있고(공공누리 제2유형·제4유형), 집계 기준이 FreeSIS 화면과 같은지는 확인하지 못했습니다.

## 활용신청 절차와 이용 조건

공공데이터포털 API 신청은 거래소 Open API보다 간단합니다. 거래소는 인증키 발급과 서비스별 이용 신청을 각각 승인받아야 하지만, 이 API는 포털 표기상 **개발단계·운영단계 모두 자동승인**입니다. 다만 금융위원회 활용가이드는 신청 후 **약 1시간 뒤부터 호출할 수 있다**고 안내합니다. 절차는 다음과 같습니다.

1. **회원가입** — 공공데이터포털(data.go.kr)에 가입하고 로그인합니다.
2. **검색** — 「금융투자협회종합통계정보」로 검색하고 `오픈 API` 탭에서 해당 API를 엽니다.
3. **활용신청** — `활용신청` 버튼을 누르고 **활용목적**(웹 사이트 개발, 앱개발, 기타, 참고자료, 연구 중 선택)을 적은 뒤, 사용할 **상세기능**을 선택하고 이용허락범위에 동의합니다.
4. **인증키 확인** — `마이페이지`의 「개인 API인증키」에서 인증키를 복사합니다.

인증키를 복사하는 버튼이 **Encoding**과 **Decoding** 두 가지입니다. 같은 키를 URL에 넣을 수 있게 변환했는지의 차이입니다. 주소 문자열에 키를 직접 붙여 넣을 때는 Encoding 키를, 프로그램 라이브러리가 요청 변수를 변환해 주는 경우에는 Decoding 키를 씁니다. <mark>변환된 키를 라이브러리에 다시 넣으면 두 번 변환돼 「등록되지 않은 인증키」 오류가 날 수 있습니다.</mark> 신청 직후라면 키를 의심하기 전에 1시간쯤 기다린 뒤 다시 호출해 봅니다.

이용 조건은 다음과 같습니다(2026년 11월 21일 공공데이터포털 화면 기준).

| 항목 | 내용 |
| :-- | :-- |
| 비용 | 무료 |
| 일일 트래픽 | 개발계정 **10,000건**. 운영계정은 활용사례를 등록하면 증가를 신청할 수 있음 |
| 한 번에 받는 행 수 | `numOfRows` 최대 10,000건 |
| 데이터 형식 | XML·JSON(REST 방식, `resultType`으로 선택, 기본값 XML) |
| 이용허락범위 | 포털 표기 「제한 없음」, 활용가이드 표기 **공공누리 제1유형**(출처표시 조건으로 상업적 이용·변경 가능) |

거래소 Open API 이용약관이 비상업 목적과 제3자 제공 금지를 정하고 있는 것과 다릅니다. 다만 공공누리 제1유형도 **출처 표시는 의무**입니다.

## 호출 예시 — 증시자금추이

API 주소는 `기본 주소 + 서비스 이름 + 기능 이름 + 요청 변수`로 구성됩니다. 활용가이드의 증시자금추이 예시는 다음과 같습니다.

```
https://apis.data.go.kr/1160100/service/GetKofiaStatisticsInfoService/getSecuritiesMarketTotalCapitalInfo?serviceKey=인증키&numOfRows=1&pageNo=1&resultType=xml&basDt=20260828
```

`basDt`는 기준일자입니다. 하루가 아니라 기간을 받으려면 `beginBasDt`와 `endBasDt`를 씁니다. 파이썬 표준 라이브러리만으로 기간을 조회하면 다음과 같습니다.

```python
import json, urllib.error, urllib.parse, urllib.request

KEY = "공공데이터포털_인증키(Decoding)"
URL = ("https://apis.data.go.kr/1160100/service/"
       "GetKofiaStatisticsInfoService/getSecuritiesMarketTotalCapitalInfo")
params = {
    "serviceKey": KEY,       # urlencode가 변환하므로 Decoding 키를 넣는다
    "resultType": "json",
    "numOfRows": 1000,       # 생략하면 10건만 온다
    "pageNo": 1,
    "beginBasDt": "20261001",  # 이 날짜 이상
    "endBasDt": "20261120",    # 이 날짜 '미만' — 11월 19일까지 조회된다
}
try:
    with urllib.request.urlopen(URL + "?" + urllib.parse.urlencode(params)) as r:
        body = json.load(r)["response"]["body"]
except urllib.error.HTTPError as e:   # 인증 오류는 401·403으로 온다
    print(e.code, e.read().decode())  # 본문에 오류 메시지와 코드가 있다
    raise
for row in body["items"]["item"]:
    print(row["basDt"], int(row["invrDpsgAmt"]) // 100_000_000, "억원")
```

호출할 때 놓치기 쉬운 조건이 네 가지 있습니다.

**① `numOfRows`를 생략하면 10건만 옵니다.** 활용가이드는 한 페이지 결과 수와 페이지 번호의 기본값을 10과 1로 안내합니다. 석 달 분량을 요청했는데 10영업일(약 2주) 분량만 돌아온다면 이 값이 원인입니다. 응답의 `totalCount`(전체 결과 수)와 받은 행 수를 비교하면 확인할 수 있습니다.

**② `endBasDt`는 그 날짜를 포함하지 않습니다.** 명세서는 `beginBasDt`를 "검색값보다 크거나 같은 데이터", <mark>`endBasDt`를 "검색값보다 **작은** 데이터"로 정의합니다.</mark> 11월 19일까지 받으려면 종료일에 11월 20일을 넣어야 합니다.

**③ 금액 단위는 원입니다.** 2026년 8월 28일 투자자예탁금 예시 값은 `99813821613132`, 즉 99조 8,138억원입니다. FreeSIS 화면의 백만원 단위 숫자와 섞으면 100만 배 차이가 납니다. 미수금 대비 반대매매 비중은 단위가 %이고, 활용가이드 예시에는 `.5`(0.5%)처럼 앞자리 0 없이 적혀 있습니다.

**④ 최신 값은 하루 이상 늦게 반영됩니다.** 금융위원회 API는 실시간이 아닙니다. 공공데이터포털 API 페이지는 기준일로부터 **영업일 하루 뒤 오후 1시 이후**에 갱신된다고 안내하지만(금요일 데이터는 다음 주 월요일), 활용가이드는 「연계받은 당일 오후 1시 이후」로 적어 두 안내가 다릅니다. 원자료인 FreeSIS 통계부터 하루 늦게 공개되므로, 아침에 받으면 최신 값이 2영업일 전 날짜일 수 있습니다. 실제 반영 시각은 인증키로 확인하지 못했습니다.

오류가 나면 응답 본문에 오류 메시지와 코드가 옵니다. 이 글을 쓰며 인증키 없이 호출하자 HTTP 401과 함께 `SERVICE_KEY_IS_NULL`(코드 20)이, 임의의 문자열을 키로 넣자 HTTP 403과 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`(코드 30)가 돌아왔습니다. 포털 안내상 활용신청을 하지 않은 API를 호출하면 `SERVICE_ACCESS_DENIED_ERROR`(코드 20), 인증키 사용 기한이 지나면 `DEADLINE_HAS_EXPIRED_ERROR`(코드 31)가 나옵니다. <mark>코드 20은 키 누락과 이용 권한 없음에 함께 쓰이므로, 번호보다 **메시지 이름**으로 원인을 구분해야 합니다.</mark>

이 사례에서 얻을 수 있는 실무 원칙은 두 가지입니다.

- **받은 데이터에는 조회한 날짜를 함께 기록합니다.** 같은 기준일의 값이라도 언제 받았느냐에 따라 다를 수 있습니다.
- **오래전에 받아 둔 값과 지금 받은 값이 다르면** 내 코드의 오류부터 의심하기 전에 원자료가 정정됐을 가능성을 확인합니다. 정정 시점은 미리 알 수 없으므로, 정기적으로 쌓는 데이터라면 분석에 쓰기 전에 해당 구간을 다시 받아 바뀐 값이 없는지 대조하는 방식이 안전합니다.

API가 지금 8월 28일 값을 정정 전 값으로 주는지 정정 후 값으로 주는지는 인증키로 직접 호출해야 알 수 있어, 이 글에서는 확인하지 못했습니다.

FreeSIS 화면은 내부 요청으로 데이터를 불러와 표를 그립니다. 그러나 협회가 이 내부 주소를 공개 서비스로 안내하지 않으므로, 이 글은 그 주소를 직접 호출하는 방법은 다루지 않습니다. **프로그램으로 받을 때는 공공데이터포털 API를, 그 밖의 통계는 화면의 파일 다운로드를** 쓰는 것이 공식 경로입니다.

## 정리

- **FreeSIS에는 자체 Open API가 없습니다.** 화면에서 엑셀·PDF 파일로 내려받을 수 있고, 금액 단위는 **백만원**입니다.
- **공식 API는 공공데이터포털**의 「금융위원회_금융투자협회종합통계정보」입니다. 제공기관 이름이 금융위원회인 이유는 금융위원회가 협회 데이터를 연계받아 개방하기 때문입니다.
- 이 API의 기능은 **8가지**입니다. 신용공여 잔고·증시자금·펀드 순자산·CMA는 일 1회, 신탁·ELS/DLS·해외파생은 월 1회 갱신되며, <mark>대차거래나 채권금리는 포함되지 않습니다.</mark>
- 신청은 회원가입 → 검색 → 활용신청 → 마이페이지 인증키 확인 순서이고 **자동승인**이며, 신청 후 약 1시간 뒤부터 호출할 수 있습니다. 개발계정 일일 트래픽은 **10,000건**입니다.
- 호출할 때는 **numOfRows 기본값 10**, **endBasDt는 그 날짜 미만**, **금액은 원 단위**를 확인하고, 최신 값이 **하루 이상 늦게** 반영된다는 점을 감안합니다.
- 협회 통계는 **공개 뒤 정정될 수 있습니다.** 2026년 8월 28일 투자자예탁금은 처음 보도된 99조 8,138억원과 현재 FreeSIS 값 98조 7,049억원이 다릅니다.
