엑셀에 관심 종목 표를 만들어 두고 매일 아침 증권사 앱을 보며 종가를 손으로 옮겨 적은 적이 있습니다. 검색해 보면 "함수 하나로 자동으로 불러온다"는 글이 많은데, 막상 따라 해 보면 지연 시간이나 이용 조건을 설명하지 않는 글이 대부분이었습니다. 이번 글에서는 공식 도움말에 적힌 조건과 제한을 기준으로 정리했습니다.

스프레드시트가 시세를 직접 불러오게 만드는 방법은 세 가지입니다. 구글 시트에는 **GOOGLEFINANCE** 함수가 있고, 엑셀(Microsoft 365)에는 **주식 데이터 형식**과 **STOCKHISTORY** 함수가 있습니다. 세 가지 모두 국내 상장 종목을 조회할 수 있지만, <mark>지연 시간과 이용 조건이 서로 다르고, 코스닥 지원처럼 공식 문서가 보장하지 않는 부분도 있습니다.</mark>

이 글은 ① 세 가지 기능으로 현재가와 일별 시세를 불러오는 수식, ② 각 기능이 공식적으로 밝힌 제한 사항, ③ 함수를 쓰지 않고 **KRX**(Korea Exchange, 한국거래소)에서 받은 파일을 엑셀에 연결하는 방법을 차례로 정리합니다. 기준 시점은 **2026년 11월**입니다. 거래소에서 파일을 내려받는 절차 자체는 [과거 주가 데이터 받는 법](https://blog.naver.com/hdglace/224404481437) 편에서 다뤘습니다.

&nbsp;

【다섯 가지 방법 비교】

| 방법 | 현재가 | 일별 시세 | 지연·갱신 | 필요한 것 |
| :-- | :-- | :-- | :-- | :-- |
| 구글 시트 GOOGLEFINANCE | ○ | ○ | 최대 20분 지연 | 구글 계정 |
| 엑셀 주식 데이터 형식 | ○ | ✕ | 20분 지연 | Microsoft 365용 Excel + Microsoft 계정(무료 가능), 편집 언어 설정 |
| 엑셀 STOCKHISTORY | ✕ | ○ | 거래일 종료 후 갱신 | Microsoft 365 유료 구독 |
| KRX 파일 + 파워 쿼리 | ✕ | ○ | 사용자가 파일을 받을 때 | KRX Data Marketplace 로그인 |
| KRX Open API + 파워 쿼리 | ✕ | ○ | 다음 날 오전 8시 이후 | Open API 인증키 |

위의 세 가지는 <mark>구글·마이크로소프트가 거래소나 데이터 업체에서 받은 시세를 보여 주는 기능</mark>이고, 아래 두 가지는 한국거래소가 직접 제공하는 원자료를 엑셀에 연결하는 방법입니다. 자료를 내 계산에 쓰기 전에 한 번 대조할 기준은 거래소 원자료입니다.

&nbsp;

【구글 시트 GOOGLEFINANCE — 종목 입력 형식】

GOOGLEFINANCE 함수의 구문은 다음과 같습니다.

```
=GOOGLEFINANCE(종목, [속성], [시작일], [종료일 또는 일수], [간격])
```

종목은 **'시장 구분자:종목코드'** 형식으로 입력합니다. 구글이 쓰는 시장 구분자는 유가증권시장이 `KRX`, 코스닥시장이 `KOSDAQ`입니다.

| 구분 | 입력 예 | 종목 |
| :-- | :-- | :-- |
| 유가증권시장 주식 | `"KRX:005930"` | 삼성전자 |
| 유가증권시장 ETF | `"KRX:069500"` | KODEX 200 |
| 코스닥시장 주식 | `"KOSDAQ:247540"` | 에코프로비엠 |

2026년 11월 12일 구글 파이낸스에서 위 세 종목은 각각 `005930:KRX`·`069500:KRX`·`247540:KOSDAQ` 주소로 종목 화면이 조회됐고, 코스닥 종목 알테오젠(196170)은 `KOSDAQ`으로는 조회되고 `KRX`로는 조회되지 않았습니다. <mark>코스닥 종목에 `KRX`를 붙이면 찾지 못합니다.</mark>

입력할 때 주의할 점이 두 가지 있습니다.

- **종목코드는 큰따옴표 안에 시장 구분자와 함께 적습니다.** 셀에 `005930`만 입력하면 숫자로 인식돼 `5930`이 될 수 있습니다.
- **시장 구분자를 생략하지 않습니다.** 생략해도 결과가 나오는 경우가 있지만, 중국 선전증권거래소도 6자리 숫자 종목코드를 쓰기 때문에 다른 종목의 시세가 나올 수 있습니다. 예를 들어 `000100`은 유가증권시장에서는 유한양행, 선전거래소(`SHE`)에서는 TCL테크놀로지입니다.

&nbsp;

【GOOGLEFINANCE 현재가 — 최대 20분 지연】

속성을 생략하면 현재가(`price`)가 나옵니다. 자주 쓰는 속성은 다음과 같습니다.

| 속성 | 내용 | 수식 예 |
| :-- | :-- | :-- |
| `price` | 현재가 | `=GOOGLEFINANCE("KRX:005930")` |
| `closeyest` | 전일 종가 | `=GOOGLEFINANCE("KRX:005930","closeyest")` |
| `changepct` | 전일 대비 등락률(%) | `=GOOGLEFINANCE("KRX:005930","changepct")` |
| `volume` | 당일 거래량 | `=GOOGLEFINANCE("KRX:005930","volume")` |
| `high52` · `low52` | 52주 최고가·최저가 | `=GOOGLEFINANCE("KRX:005930","high52")` |
| `marketcap` | 시가총액 | `=GOOGLEFINANCE("KRX:005930","marketcap")` |
| `datadelay` | 현재가의 지연 시간 | `=GOOGLEFINANCE("KRX:005930","datadelay")` |

**현재가는 실시간이 아닙니다.** 구글이 공개한 거래소별 지연 시간 표에는 한국거래소(KRX)와 코스닥(KOSDAQ)이 모두 **20분**으로 적혀 있고, 함수 도움말도 시세가 최대 20분 지연될 수 있다고 안내합니다. <mark>장중에 주문 가격을 정하는 용도로는 쓸 수 없습니다.</mark> 실제 지연 시간은 `datadelay` 속성으로 확인할 수 있습니다.

52주 최고가·최저가(`high52`·`low52`)가 종가 기준인지 장중 가격 기준인지는 도움말에 적혀 있지 않습니다. 두 기준의 차이는 [52주 신고가·신저가 종목 찾는 법](https://blog.naver.com/hdglace/224414554438) 편에서 다뤘습니다.

&nbsp;

【GOOGLEFINANCE 일별 시세 — 날짜를 넣으면 표로 나온다】

시작일과 종료일을 넣으면 함수가 과거 시세 표를 반환합니다. 이때 쓸 수 있는 속성은 `open`(시가)·`close`(종가)·`high`(고가)·`low`(저가)·`volume`(거래량)·`all`(전부) 여섯 가지이고, 간격은 `"DAILY"`(일별) 또는 `"WEEKLY"`(주별)입니다.

```
=GOOGLEFINANCE("KRX:005930","close",DATE(2026,10,1),DATE(2026,10,31),"DAILY")
```

이 수식은 **날짜·종가 두 열**의 표를 반환합니다. `"close"` 대신 `"all"`을 넣으면 날짜·시가·고가·저가·종가·거래량 여섯 열이 나옵니다. 종료일 자리에 숫자를 넣으면 시작일부터의 일수로 계산하고, 종료일을 생략하면 시작일 하루치만 나옵니다.

일별 시세를 쓸 때 공식 도움말이 밝힌 제한 사항은 다음과 같습니다.

- **날짜는 협정 세계시 정오로 처리됩니다.** 도움말 원문은 "GOOGLEFINANCE에 입력한 날짜는 **UTC**(Coordinated Universal Time, 협정 세계시) 정오로 처리되며, 그 시각 이전에 마감하는 거래소는 날짜가 하루 밀릴 수 있다"입니다. 한국 정규시장 마감인 오후 3시 30분은 UTC로 오전 6시 30분이라 이 조건에 해당합니다. <mark>결과 표의 날짜와 종가를 KRX 자료의 같은 날짜와 한 번 대조한 뒤 사용해야 합니다.</mark>
- **스크립트로는 과거 시세를 가져올 수 없습니다.** 과거 데이터는 Sheets **API**(Application Programming Interface, 응용 프로그램 인터페이스)나 Apps Script로 내려받거나 읽을 수 없고, 시도하면 해당 셀에 `#N/A` 오류가 표시됩니다. 시트 안에서 수식으로 보는 것까지만 허용됩니다.
- **조회 가능한 시작 시점이 공개돼 있지 않습니다.** 도움말은 종목별로 과거 시세가 언제부터 있는지 밝히지 않습니다. 몇 년 전까지 필요하다면 원하는 시작일을 넣어 표의 첫 행 날짜를 확인해야 합니다.
- **수정주가 적용 여부가 적혀 있지 않습니다.** 액면분할·병합이 있었던 종목은 분할 전 가격이 조정돼 나오는지 도움말로는 알 수 없습니다. 이런 종목은 KRX의 「수정주가 적용」 자료와 대조해야 합니다(수정주가는 [액면분할·주식병합](https://blog.naver.com/hdglace/224425710598) 편 참고).
- **전문가 용도로는 쓸 수 없습니다 — 현재가·일별 시세 모두.** 도움말은 금융업계 전문가나 비금융 회사(정부 기관 포함)의 전문가는 이 데이터를 쓸 수 없다고 밝히고, 데이터는 정보 제공 목적으로 '있는 그대로' 제공됩니다.

【IMPORTXML로 포털 화면을 읽는 방법은 다루지 않습니다】

구글 시트에는 웹페이지의 특정 부분을 읽어 오는 **IMPORTXML** 함수도 있습니다. 검색하면 이 함수로 포털 증권 화면의 현재가를 가져오는 방법이 많이 나오지만, 이 글에서는 안내하지 않습니다. 이유는 이용약관입니다.

- **네이버 서비스 이용약관**(2026년 10월 1일 시행)은 네이버의 사전 허락 없이 매크로·봇·스크래퍼 같은 자동화된 수단으로 "이용자(사람)의 실제 이용을 전제로 하는 네이버 서비스의 제공 취지에 부합하지 않는 방식으로" 서비스를 이용하는 행위를 금지합니다.
- **KRX Data Marketplace 홈페이지 이용약관**은 제10조 제2호에서 "자동화 수단을 이용하여 정보를 무단 수집·복제·배포하는 행위"를 금지 행위로 명시합니다. 이 사이트는 2025년 12월부터 로그인해야 조회할 수 있어 함수로 읽어 올 수도 없습니다.

<mark>시트가 일정 주기로 웹페이지를 다시 읽는 방식은 사람이 화면을 보는 것과 다른 자동 수집입니다.</mark> 거래소 원자료를 자동으로 받고 싶다면 아래에서 다룰 Open API가 약관이 허용한 경로입니다.

【엑셀 주식 데이터 형식 — 현재가와 종목 정보】

엑셀의 **주식 데이터 형식**은 셀에 입력한 종목을 시세 정보와 연결하는 기능입니다. 사용 절차는 다음과 같습니다.

1. 셀에 종목을 입력합니다. 한국거래소 종목은 `XKRX:005930`처럼 **MIC**(Market Identifier Code, 시장 식별 코드)와 종목코드를 함께 적으면 거래소가 특정됩니다(이 형식은 STOCKHISTORY 도움말과 마이크로소프트 Q&A 답변이 안내하는 형식이고, 주식 데이터 형식 도움말 자체는 종목코드·회사명·펀드명 입력만 안내합니다).
2. 셀을 선택한 상태에서 **데이터** 탭의 **주식**을 누릅니다.
3. 연결된 셀 옆에 나타나는 단추를 눌러 가격·전일 대비 등락 같은 필드를 옆 열에 추가합니다.

이용 조건이 두 가지 있습니다.

- **Microsoft 365 계정 또는 무료 Microsoft 계정**으로 로그인해야 합니다. 도움말의 적용 대상은 Microsoft 365용 Excel(Windows·Mac)이며, 구독 없는 Excel 2019·2021 설치판은 적용 대상에 없습니다.
- **Office 언어 기본 설정에 영어·프랑스어·독일어·이탈리아어·스페인어·포르투갈어 중 하나를 편집 언어로 추가**해야 합니다. <mark>편집 언어가 한국어 하나뿐이면 이 조건을 충족하지 못합니다.</mark>

시세는 **LSEG**(London Stock Exchange Group, 런던증권거래소그룹) Data & Analytics가 제공하고, 마이크로소프트의 지원 거래소 표에 한국거래소(XKRX)는 **20분** 지연으로 올라 있습니다. 같은 표에 코스닥은 별도 항목으로 적혀 있지 않습니다. 코스닥 종목을 입력했을 때는 데이터 선택 창에 표시되는 종목명과 시장을 확인해야 합니다. 마이크로소프트는 이 시세가 지연되고 '있는 그대로' 제공되며 거래 목적이나 투자 조언용이 아니라고 안내합니다.

【엑셀 STOCKHISTORY — 일별 시세를 표로】

과거 시세는 **STOCKHISTORY** 함수로 불러옵니다.

```
=STOCKHISTORY("XKRX:005930",DATE(2026,10,1),DATE(2026,10,31),0,1,0,1,5)
```

인수는 차례로 종목, 시작일, 종료일, 간격, 머리글, 표시할 열입니다.

| 인수 | 값 |
| :-- | :-- |
| 간격 | 0 일별(기본값) · 1 주별 · 2 월별 |
| 머리글 | 0 없음 · 1 표시(기본값) · 2 종목 식별자와 머리글 표시 |
| 표시할 열 | 0 날짜 · 1 종가 · 2 시가 · 3 고가 · 4 저가 · 5 거래량 (생략하면 날짜·종가) |

위 수식은 머리글이 있는 날짜·종가·거래량 세 열의 표를 반환합니다. 주의할 점은 세 가지입니다.

- **유료 구독이 필요합니다.** STOCKHISTORY는 Microsoft 365 Personal·Family·Business Standard·Business Premium 구독에서만 쓸 수 있습니다. 무료 계정으로 쓸 수 있는 주식 데이터 형식과 조건이 다릅니다.
- **당일 시세는 장 마감 후에 반영됩니다.** 마이크로소프트는 이 함수가 "일반적으로 거래일이 완료된 후에만 업데이트된다"고 안내합니다. 장중 가격은 주식 데이터 형식으로 확인해야 합니다.
- **갱신이 멈출 수 있습니다.** 2026년 9월 마이크로소프트 커뮤니티에 한국 주식·ETF(Exchange Traded Fund, 상장지수펀드)의 STOCKHISTORY 데이터가 9월 7일 이후 갱신되지 않는다는 문의가 올라왔습니다. 답변자(마이크로소프트 외부 중재자)는 처음에 '거래일이 끝난 뒤에야 반영되는 정상 동작'(미국 종목은 노동절 휴장)으로 봤다가, 다른 사용자도 같은 현상을 보고하고 있다며 공통 데이터 서비스 문제로 보인다고 정정했고, 공식 장애 번호나 복구 시점은 공개되지 않았다고 밝혔습니다. <mark>함수 결과에 최근 날짜가 누락돼 있으면 수식 오류보다 데이터 공급 문제를 먼저 의심해야 합니다.</mark>

【KRX 파일을 엑셀에 연결하기 — 파워 쿼리】

거래소에서 받은 파일을 매번 복사해 붙이지 않고, 엑셀이 폴더 안의 파일을 읽어 하나의 표로 합치게 할 수 있습니다. 엑셀에 내장된 **파워 쿼리** 기능을 씁니다.

1. KRX Data Marketplace의 「전종목 시세」에서 받은 CSV(Comma-Separated Values, 쉼표로 구분한 값) 파일을 폴더 하나에 저장합니다. **파일 이름을 `20261111.csv`처럼 거래일로 지정합니다.**
2. **데이터** 탭 → **데이터 가져오기** → **파일에서** → **폴더에서**를 선택하고 그 폴더를 지정합니다.
3. 파일 목록이 나오면 **결합 및 로드**를 선택합니다. 엑셀이 폴더 안의 파일을 하나의 표로 이어 붙입니다.
4. 다음 날 새 파일을 같은 폴더에 저장한 뒤 **데이터** 탭의 **모두 새로 고침**을 누르면 표에 추가됩니다.

여기서 필요한 조치가 세 가지입니다.

- **파일 이름을 날짜로 쓰는 이유**: 폴더 결합 결과에는 각 행이 어느 파일에서 왔는지 보여 주는 원본 파일 이름 열(`Source.Name`)이 추가됩니다. <mark>「전종목 시세」는 날짜 하나를 지정해 받는 자료이므로, 파일 이름이 곧 그 행의 거래일이 됩니다.</mark>
- **모든 파일의 열 구성이 같아야 합니다.** 마이크로소프트는 폴더 결합의 조건으로 각 파일의 열 머리글·데이터 형식·열 개수가 같아야 한다고 안내합니다. 같은 화면에서 같은 형식(CSV)으로 받은 파일만 넣어야 합니다.
- **종목코드 열은 텍스트로 지정합니다.** 숫자로 인식되면 `005930`이 `5930`이 됩니다. 쿼리 편집 화면에서 종목코드 열의 데이터 형식을 텍스트로 바꿉니다. 한글 종목명이 깨져 보이면 같은 화면에서 파일 원본(문자 인코딩)을 한국어로 바꿉니다.

이 방법은 수정주가가 적용되지 않는다는 한계가 있습니다. 하루치 파일은 그날의 가격 그대로이므로, 액면분할이 있었던 종목은 분할 전후 가격이 이어지지 않습니다([과거 주가 데이터 받는 법](https://blog.naver.com/hdglace/224404481437) 편의 「수정주가 적용」 절 참고).

【KRX Open API를 엑셀에 연결하기】

파일을 받는 과정까지 자동으로 처리하려면 **KRX Open API**를 씁니다. 인증키 신청과 API별 활용신청 두 단계를 거쳐야 호출할 수 있고, 하루 10,000회까지 호출할 수 있습니다(신청 절차는 [과거 주가 데이터 받는 법](https://blog.naver.com/hdglace/224404481437) 편 참고).

엑셀 파워 쿼리의 **웹** 커넥터는 요청 헤더를 지정할 수 있어 이 API를 직접 호출할 수 있습니다.

1. **데이터** 탭 → **웹**을 선택하고 **고급**을 누릅니다.
2. URL에 서비스 주소와 기준일자를 넣습니다. 유가증권시장 일별매매정보는 `https://data-dbg.krx.co.kr/svc/apis/sto/stk_bydd_trd?basDd=20261111`, 코스닥은 `sto/ksq_bydd_trd`입니다.
3. HTTP 요청 헤더에 이름 `AUTH_KEY`, 값에 발급받은 인증키를 넣습니다. 헤더 이름 목록에 `AUTH_KEY`는 없으므로 직접 입력합니다. 이 방식으로 인증 오류(401)가 나면 쿼리 편집 화면의 **고급 편집기**에서 `Json.Document(Web.Contents("https://data-dbg.krx.co.kr/svc/apis/sto/stk_bydd_trd?basDd=20261111", [Headers=[AUTH_KEY="발급받은 키"]]))`처럼 코드로 헤더를 넣습니다.
4. 응답은 JSON 형식이며, 쿼리 편집 화면에서 표로 변환합니다.

호출 1회가 반환하는 것은 **기준일자 하루치 전 종목**이고, 열에는 기준일자·종목코드·종목명·종가·시가·고가·저가·거래량·거래대금·시가총액이 포함됩니다. 기준일자 열이 포함돼 있어 파일 이름으로 날짜를 관리할 필요가 없습니다.

제한 사항도 분명합니다.

- **당일 시세는 없습니다.** 직전 거래일 자료가 다음 날 오전 8시 이후에 조회됩니다. 현재가 확인 용도로는 쓸 수 없습니다.
- **인증키가 통합 문서에 저장됩니다.** 요청 헤더에 넣은 키는 쿼리 정의에 함께 저장됩니다. KRX Open API 이용약관은 인증키의 양도와 데이터의 제3자 제공을 금지하고 비상업적 목적으로만 이용을 허용하므로, <mark>키가 저장된 엑셀 파일은 다른 사람에게 보내지 않아야 합니다.</mark>

【정리】

- **구글 시트 GOOGLEFINANCE**는 `"KRX:종목코드"`(코스피)·`"KOSDAQ:종목코드"`(코스닥) 형식으로 현재가와 일별 시세를 불러옵니다. 현재가는 **최대 20분 지연**이고, 과거 시세는 날짜가 하루 밀릴 수 있어 KRX 자료와 대조가 필요합니다.
- **엑셀 주식 데이터 형식**은 무료 Microsoft 계정으로도 쓸 수 있지만 **편집 언어에 영어 등을 추가**해야 하고, 시세는 20분 지연입니다.
- **엑셀 STOCKHISTORY**는 유료 구독이 필요하고 장 마감 후에 갱신됩니다. 데이터 갱신이 멈췄다는 사용자 문의 사례가 있었습니다(공식 확인은 없음).
- **포털 화면을 IMPORTXML로 읽어 오는 방법**은 이용약관이 금지하는 자동 수집에 해당할 수 있어 다루지 않았습니다.
- **거래소 원자료를 쓰려면** 「전종목 시세」 파일을 폴더에 모아 파워 쿼리로 결합하거나, Open API를 웹 커넥터로 호출합니다. 두 방법 모두 당일 장중 시세는 제공하지 않습니다.

매일 아침 브리핑의 지수·종목 수치는 정규장 종가 기준입니다. 스프레드시트 함수로 불러온 숫자와 차이가 날 때 어느 값을 기준으로 삼아야 하는지가 이 글의 결론입니다.
