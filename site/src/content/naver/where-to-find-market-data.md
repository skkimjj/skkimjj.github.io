저는 한동안 "외국인이 사흘 연속 순매수했다"는 기사를 그냥 믿고 읽었습니다. 그런데 어느 날 같은 날짜 기사 두 개가 <mark>서로 다른 순매수 금액을 적어 놓은 걸</mark> 봤습니다.

둘 다 틀린 게 아니었습니다. 하나는 **오후 4시쯤** 정규시장 기준 숫자였고, 다른 하나는 **저녁 6시 이후** 시간외까지 합친 숫자였습니다. 기준 시점이 달랐던 거죠.

그때부터 숫자는 되도록 **그 숫자를 처음 공표한 원 소스를 찾아** 직접 확인하기로 했습니다. 놀랍게도 이게 다 무료였습니다. 오늘은 제가 실제로 쓰는 무료 사이트 다섯 곳을 정리해 보겠습니다.

&nbsp;

【📍 왜 원 소스를 직접 확인해야 하나】

기사·블로그·증권사 앱은 거래소나 감독원이 만든 데이터를 받아 다시 정리한 **2차 자료**입니다. 정리 과정에서 이 세 가지가 자주 사라집니다.

| 사라지는 정보 | 왜 중요한가 |
| :--- | :--- |
| **기준 시점** | "ETF 순자산 500조"가 어제인지 두 달 전인지에 따라 뜻이 다릅니다 |
| **집계 범위** | 코스피만인지 코스닥 포함인지, 어느 투자자 구분까지인지 |
| **잠정치인지** | 장 종료 직후 수치는 뒤에 정정될 수 있습니다 |

<mark>1차 소스 화면에는 이 세 가지가 거의 항상 함께 적혀 있습니다.</mark> 제가 헷갈렸던 순매수 금액도, 원 소스에 가 보니 "몇 시 이후 제공"이라고 화면에 써 있었습니다.

&nbsp;

【① 한국거래소 정보데이터시스템 — 시세·수급·공매도】

가장 먼저 익힐 곳입니다. **KRX**(Korea Exchange, 한국거래소)가 운영하는 데이터 포털이고 주소는 **data.krx.co.kr** 입니다.

⚠️ 그런데 제가 예전에 정리해 둔 메모가 지금은 안 맞더군요. <mark>2025년 12월 27일 개편으로 사이트 이름이 '정보데이터시스템'에서 **KRX Data Marketplace**로 바뀌었고, 조회하려면 로그인이 필요해졌습니다.</mark> AI 봇의 무단 수집으로 서버 부하가 커진 게 이유라고 합니다. 네이버·카카오 아이디로 가입할 수 있고 **조회는 종전대로 무료**입니다. 예전 이름과 "로그인 없이"로 안내하는 글이 아직 많으니 참고하세요.

2026년 8월 현재 대메뉴는 여섯 개인데, 실제로 쓰는 건 **[통계]** 하나입니다.

| 메뉴 | 들어 있는 것 |
| :--- | :--- |
| **통계** | 기본통계·이슈통계·공매도통계 — 여기만 알면 됩니다 |
| **쉽게 보는 통계** | 주요통계·순위통계·시각화통계 |
| **깊이 있는 통계** | 기업분석보고서·투자분석정보·ESG정보 |
| **간행물** | 시장동향·발간자료 |
| **데이터 상품** | 유료 영역이 여기 따로 모여 있습니다 |

<mark>로그인만 하면 조회는 무료이고, 결과는 엑셀·CSV·PDF로 내려받을 수 있습니다.</mark>

▶ **투자자별 거래실적** — `[통계] → [기본통계] → [주식] → [거래실적]`. 시장 전체용과 개별종목용 두 화면이 있습니다.

여기서 제가 헤맸던 그 함정이 나옵니다. <mark>정규장분은 장이 끝난 뒤에 올라오고, 시간외까지 더한 당일 전체는 시간외 거래가 끝나는 오후 6시 이후에 올라옵니다.</mark> 장 끝나고 바로 본 숫자는 시간외가 빠진 값이라는 뜻입니다.

▶ **"시간외가 오후 6시요? 8시까지 아닌가요?"**

저도 여기서 한 번 더 헷갈렸습니다. **한국거래소(KRX)의 하루는 시간외 단일가매매가 끝나는 18:00까지**입니다. 20:00까지 열리는 건 대체거래소 **넥스트레이드**(NXT)의 애프터마켓이고, 이건 **다른 시장**입니다.

그래서 중요한 게 따라옵니다. <mark>한국거래소가 내놓는 통계는 한국거래소에서 체결된 거래를 집계한 값입니다.</mark> 넥스트레이드 거래는 넥스트레이드가 따로 공표하고, 뉴스에서 "두 시장 합산"이라고 하면 그 둘을 더한 숫자입니다.

⚠️ 이 시간표는 **2026년 9월 14일에 바뀔 예정**입니다. 한국거래소가 애프터마켓(16:00~20:00)을 신설하고 시간외 단일가매매를 폐지하기로 해서, 그때부터는 거래소의 하루도 20:00까지 늘어납니다. 시행 전 제도라 일정은 바뀔 수 있습니다.

▶ **공매도 통계** — 같은 사이트 안 `[통계] → [공매도통계]`입니다. 하위에 **공매도 종합정보 · 공매도 거래 · 공매도 순보유잔고 · 공매도 과열 · 대차 정보 · 공매도 제도**가 있습니다. 예전에 쓰던 공매도 종합포털(short.krx.co.kr) 주소는 <mark>지금 이 메뉴로 자동 연결됩니다.</mark>

공매도 **잔고**는 보고의무 발생일(T)로부터 2영업일(T+2)까지 보고하게 되어 있습니다. 즉 <mark>오늘 화면에는 2영업일 전 잔고까지만 보입니다.</mark> 저는 이걸 모르고 "오늘 공매도 잔고"라고 말한 적이 있는데, 실은 이틀 전 사진이었습니다.

▶ **ETF 전종목 정보** — `[통계] → [기본통계] → [증권상품] → [ETF]`. 상장 **ETF**(Exchange Traded Fund, 상장지수펀드) 전 종목의 시세·순자산·기초지수·괴리율을 한 표로 받습니다. 종목 화면을 하나씩 여는 것보다 훨씬 빠릅니다.

&nbsp;

【② 금융투자협회 — 보수·채권금리·시장통계】

ETF 비용과 채권금리는 거래소가 아니라 협회 쪽이 본류입니다. 사이트가 갈라져 있어서 처음엔 헷갈렸는데, 세 곳이면 충분합니다.

| 사이트 | 주소 | 무엇을 보는가 |
| :--- | :--- | :--- |
| 전자공시서비스 | dis.kofia.or.kr | 펀드별 **보수·비용 비교** |
| 채권정보센터 | kofiabond.or.kr | 국고채 등 **채권 금리** |
| 종합통계(FreeSIS) | freesis.kofia.or.kr | **자본시장 전체** 시계열 통계 |

전자공시서비스의 `펀드별 보수비용비교` 화면은 총보수와 실제 비용을 나란히 보여 줍니다. 표기 보수보다 실부담이 큰 이유를 여기서 눈으로 확인할 수 있습니다.

채권정보센터는 상단 `[채권시가평가] → [채권시가평가기준수익률]`로 들어가면 국고채·금융채·지방채·특수채 금리가 한 화면에 나옵니다.

**FreeSIS**(Free Statistics and Info Services, 종합통계 포털)는 협회가 흩어져 있던 자본시장 통계를 한곳에 모아 둔 시계열 데이터베이스입니다. 2026년 8월 현재 **주식·채권·파생상품·자산관리·펀드·자문일임·신탁·단기자금·금융투자업자** 아홉 갈래입니다.

앞의 두 곳이 '개별 상품'을 보는 자리라면 <mark>FreeSIS는 '시장 전체'를 보는 자리입니다.</mark> 저는 펀드 설정액이나 투자자예탁금이 몇 년째 어떻게 움직였는지 볼 때 씁니다. 한 시점의 값이 아니라 **추세**가 필요할 때 유용합니다.

&nbsp;

【③ DART — 기업이 직접 낸 서류】

**DART**(Data Analysis, Retrieval and Transfer System, 전자공시시스템)는 금융감독원이 운영합니다. 주소는 **dart.fss.or.kr** 이고 로그인 없이 열람됩니다.

제가 실제로 쓰는 건 두 곳뿐입니다.

- **[공시서류검색] → [공시통합검색]** — 회사명·기간·보고서 종류로 찾기
- **[최근공시]** — 방금 접수된 공시가 시간순으로 흐릅니다

▶ 그런데 DART에서 제일 헷갈리는 게 **실적이 언제 올라오나**입니다. 기업이 아무 때나 올리는 게 아니라 **법으로 기한이 정해져 있습니다.**

- **사업보고서(연간)** — 사업연도가 끝난 뒤 **90일** 이내
- **반기보고서** — 반기가 끝난 뒤 **45일** 이내
- **분기보고서** — 분기가 끝난 뒤 **45일** 이내

예외가 하나 있습니다. 연결기준 분기·반기보고서를 **처음 제출하는 법인**은 최초 사업연도와 그다음 사업연도에 한해 **60일**이 적용됩니다.

12월 결산법인으로 바꿔 보면 실제 마감일은 이렇습니다.

| 보고서 | 2026년 마감일 | 연결기준 최초 제출 시 |
| :--- | :--- | :--- |
| 사업보고서(2025년치) | **3월 31일** | — |
| 1분기보고서 | **5월 15일** | 6월 1일 |
| 반기보고서 | **8월 14일** | 8월 31일 |
| 3분기보고서 | **11월 16일** | 11월 30일 |

<mark>이 글이 올라가는 이번 주가 바로 반기보고서 마감 주입니다(8월 14일).</mark> 마감이 가까우면 하루에 수백 건씩 접수되니, 관심 종목의 반기 실적은 이 시기 `최근공시`를 지켜보면 됩니다.

&nbsp;

【④ 세이브로 — 배당·발행 정보】

**세이브로**(SEIBro)는 한국예탁결제원이 운영하는 증권정보포털입니다. **seibro.or.kr**, 회원가입 없이 무료입니다.

거래소가 '거래'를, DART가 '서류'를 맡는다면 <mark>예탁결제원은 주식의 '권리' 쪽을 맡습니다.</mark>

- **배당정보** — 종목별 배당기준일·주당배당금 이력
- **주식 발행정보** — 증자·감자·액면분할·병합 이력
- **ETF 종목발행현황** — 상장 ETF의 발행·설정 현황

제가 과거 주가를 비교하다 크게 헛발질한 적이 있는데, 원인이 **액면분할**이었습니다. 분할 전후 주가를 그대로 이으면 그래프가 절벽처럼 꺾입니다. 그 이력이 여기 있습니다.

&nbsp;

【⑤ 한국은행 ECOS — 금리·물가·환율】

시장 데이터가 아니라 **경제 데이터**가 필요할 때 갑니다. **ECOS**(Economic Statistics System, 한국은행 경제통계시스템), 주소는 **ecos.bok.or.kr** 입니다.

기준금리·시장금리·환율·물가·통화량을 시계열로 주고, 자주 쓰는 지표를 모은 **100대 통계지표** 코너가 있습니다. 물가·고용 같은 국가 통계 전반은 국가통계포털 **kosis.kr** 이 담당합니다.

&nbsp;

【🔧 한 걸음 더 — 무료 오픈 API】

같은 숫자를 매일 손으로 옮기고 있다면 **API**(Application Programming Interface, 프로그램끼리 데이터를 주고받는 규격)를 쓸 수 있습니다. 세 곳 다 무료입니다.

| 서비스 | 주소 | 발급·한도 |
| :--- | :--- | :--- |
| KRX Open API | openapi.krx.co.kr | Data Marketplace 가입 후 인증키 신청(승인 필요) |
| OpenDART | opendart.fss.or.kr | 개인 즉시 발급, **일일 2만 건** |
| 한국은행 Open API | ecos.bok.or.kr/api | 가입 시 인증키 자동 부여 |

KRX Open API는 2026년 8월 현재 7개 부문 **31종**입니다. 개수보다 중요한 건 무엇을 주느냐인데, 이렇게 나뉩니다.

| 부문 | 받을 수 있는 데이터 |
| :--- | :--- |
| **주식** (8종) | 유가증권·코스닥·코넥스 일별 매매정보와 종목 기본정보, 신주인수권 |
| **파생상품** (6종) | 선물·옵션 일별 매매정보 |
| **지수** (5종) | KRX·KOSPI·KOSDAQ 시리즈, 채권·파생상품지수 |
| **증권상품** (3종) | ETF·ETN·ELW 일별 매매정보 |
| **채권** (3종) | 국채전문유통·일반채권·소액채권시장 |
| **일반상품** (3종) | 석유·금·배출권 시장 |
| **ESG** (3종) | ESG 증권상품, 사회책임투자채권, ESG 지수 |

이름에서 보이듯 대부분 <mark>**일별 매매정보**입니다 — 실시간 시세가 아니라 하루 단위로 마감된 데이터입니다.</mark> 제공 기간은 2010년 이후입니다.

정부·공공기관 데이터를 모은 **공공데이터포털**(data.go.kr)에도 금융위원회가 제공하는 주식시세정보·상장종목정보 API가 올라와 있습니다.

&nbsp;

【⚠️ 제가 실제로 걸렸던 함정 5가지】

1. **잠정치를 확정치로 읽었다.** 투자자별 매매(정규장분 → 시간외 마감 후 전체분), 공매도 잔고(T+2)가 대표 예입니다. <mark>화면에 뜬 숫자가 언제 기준인지 확인하는 게 첫 기술입니다.</mark>
2. **과거 주가를 그대로 비교했다.** 액면분할·증자가 있었으면 이어지지 않습니다.
3. **총보수를 실부담으로 착각했다.** 기타비용·매매중개수수료가 따로 붙습니다.
4. **메뉴 이름을 외웠다.** 거래소·협회 사이트는 개편이 잦습니다. 당장 KRX가 이름과 로그인 정책을 바꿨고 공매도 포털은 본 사이트로 흡수됐습니다. 경로가 바뀌면 사이트 내부 검색으로 항목 이름(예: '투자자별 거래실적')을 찾는 게 빠릅니다.
5. **데이터를 예측 근거로 곧바로 썼다.** 1차 데이터는 "무슨 일이 있었나"는 정확히 알려 주지만 "앞으로 어떻게 되나"는 알려 주지 않습니다.

【📝 오늘의 정리】

- **1차 소스를 봐야 하는 이유** — 기준 시점·집계 범위·잠정 여부가 2차 자료에서 사라집니다.
- **거래소**(data.krx.co.kr) = 시세·투자자별 거래실적·ETF 전종목. <mark>2025년 12월 27일부터 로그인 필요(조회는 무료), 이름은 KRX Data Marketplace.</mark>
- **투자자별 매매**는 정규장분 → 오후 6시 이후 전체분 순으로 올라오고, 이건 <mark>KRX 체결분 기준</mark>입니다(20:00까지 여는 NXT는 별도 시장·별도 공표). **공매도 잔고**는 T+2까지 보고, 경로는 `[통계] → [공매도통계]`.
- **금융투자협회** = 보수(dis)·채권금리(kofiabond)·자본시장 시계열 통계(freesis).
- **DART** = 기업 서류. 정기보고서 기한은 사업보고서 **90일**, 분기·반기 **45일**.
- **세이브로** = 배당·증자·분할 이력, **ECOS** = 금리·물가·환율.
- **무료 오픈 API** 세 곳(KRX·OpenDART·한국은행). OpenDART는 일일 2만 건, KRX는 31종이며 대부분 **일별** 데이터.

다음 편에서는 **FOMC**(Federal Open Market Committee, 미 연방공개시장위원회)를 다루겠습니다. 점도표와 성명문이 각각 무엇이고, 새벽에 나오는 발표를 어디서 확인하는지 정리하겠습니다.
